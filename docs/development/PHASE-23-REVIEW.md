Smallest remedy: associate attributable errors with the corresponding field using the existing `FormField` slot; keep a form-level alert for non-field errors.
- **P2, eager nested queries:** `apps/web/src/views/ProjectView.vue:476–484,551–557` renders `EpisodeScenes` in a closed-by-default disclosure; `apps/web/src/components/EpisodeScenes.vue:170–178,264–268` does likewise for `SceneCuePoints`. `apps/web/src/components/ui/AccordionItem.vue:2–6` and `AccordionContent.vue:1–3` contain no conditional mounting; nested `useQuery` calls have no disclosure-based `enabled` guard (`EpisodeScenes.vue:24–38`; `SceneCuePoints.vue:19–32`). Thus the source indicates requests can fan out across collapsed episodes/scenes after data loads; actual network counts were not measured. Smallest remedy: mount nested components on open or gate their queries while closed; test collapsed disclosures do not request descendants. Existing mocked authoring and media-assignment workflows (`apps/web/src/views/ProjectWorkflow.test.ts:177`, `apps/web/src/views/MediaWorkflow.test.ts:358`) do not establish that property or upload-error association.
